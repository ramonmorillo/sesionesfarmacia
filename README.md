# Sesiones Clínicas - Servicio de Farmacia

Este repositorio es **solo un almacén de código**. La ejecución final se realiza en **Google Apps Script** vinculado a un **Google Sheet**.

## Importante
- Este repositorio no contiene datos reales.
- La base de datos está en Google Sheets con las pestañas:
  - `Sesiones`
  - `Profesionales`
  - `TiposSesion`
  - `HistorialCambios`
- Deben existir exactamente las columnas definidas para cada pestaña.

## Archivos para Apps Script
Copiar y pegar en el editor de Apps Script:
- `Code.gs`
- `Index.html`
- `Styles.html`
- `Scripts.html`

## Despliegue
1. Abrir Google Sheet.
2. Ir a **Extensiones > Apps Script**.
3. Crear los archivos `Code.gs`, `Index.html`, `Styles.html` y `Scripts.html`.
4. Copiar el contenido desde este repositorio.
5. Implementar como **aplicación web**.
6. Ejecutar como **el propietario**.
7. Configurar acceso inicialmente para el propietario o usuarios autorizados.
